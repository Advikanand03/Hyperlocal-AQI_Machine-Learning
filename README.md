This project aims to develop a hyperlocal AQI monitoring framework that first infers fine-scale air-quality patterns using sparse regulatory CAAQMS stations and auxiliary datasets, and then uses model error and uncertainty to guide efficient deployment of a minimal number of low-cost sensors.

Bangalore was chosen as the primary city as it has a fair amount of caaqms stations and other data can also be provided for a big tier-1 city. Other cities have not been decided but will be selected in a decreasing order of the datasets related with that city.
